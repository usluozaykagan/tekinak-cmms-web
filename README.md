# Tekinak Gıda CMMS - Web Portalı

Tekinak Gıda San. ve Tic. A.Ş. (Berrak Makarna) Endüstriyel Bakım & Arıza Yönetim Portalı (CMMS).

## 🚀 GitHub Pages ile Doğrudan Kullanım

Bu depo, Android uygulamasıyla gerçek zamanlı senkronize çalışan CMMS Web Portalını barındırır.

### Özellikler
- **Arıza Bildirim & Müdahale Yönetimi:** Ses, görsel ve departman filtreli takip.
- **İş Emirleri & Teknisyen Görevlendirme:** Sorumlu ataması ve durum takibi.
- **Periyodik Bakım & Revizyon Takvimi:** Bakım tarihi ve kaç gün sonra tekrarlanacağı bağımsız seçilir.
- **Orijinal Microsoft Excel (.xlsx) Raporlama:** Tarih aralığı filtreli çok sayfalı rapor çıktısı.
- **Güvenli Kimlik Doğrulama:** Firebase Authentication ile şifrelenmiş giriş.
- **Mobil & Masaüstü Uyumlu:** Tailwind CSS & Lucide Icons ile modern fabrika arayüzü.

### GitHub Pages Kurulumu
1. **Settings > Pages** sekmesine gidin.
2. **Branch:** `main` (veya `master`), **Folder:** `/ (root)` seçip **Save** butonuna tıklayın.
3. Firebase Console üzerinde **Authentication > Settings > Authorized Domains** kısmına `<kullanici-adiniz>.github.io` adresini ekleyin.
